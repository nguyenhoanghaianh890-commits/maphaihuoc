Tài Liệu & Hướng Dẫn Tích Hợp

Tương thích 100% với chuẩn OpenAI Chat Completions API. Bạn có thể sử dụng bất kỳ thư viện hoặc ứng dụng tương thích nào.

BASE URL (API ENDPOINT)
https://tuangpt.top/v1
MODEL BẮT BUỘC
wormgpt
BASH / CURL 
curl https://tuangpt.top/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-worm-your-api-key" \
  -d '{
    "model": "wormgpt",
    "messages": [
      {"role": "user", "content": "Xin chào, hãy giới thiệu về bạn."}
    ],
    "stream": true
  }'
PYTHON (pip install openai) 
from openai import OpenAI

client = OpenAI(
    base_url="https://tuangpt.top/v1",
    api_key="sk-worm-your-api-key"
)

response = client.chat.completions.create(
    model="wormgpt",
    messages=[
        {"role": "user", "content": "Xin chào, WormGPT!"}
    ],
    stream=True
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)
NODE.JS (npm install openai) 
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'https://tuangpt.top/v1',
  apiKey: 'sk-worm-your-api-key',
});

async function main() {
  const stream = await openai.chat.completions.create({
    model: 'wormgpt',
    messages: [{ role: 'user', content: 'Xin chào!' }],
    stream: true,
  });

  for await (const chunk of stream) {
    process.stdout.write(chunk.choices[0]?.delta?.content || '');
  }
}

main();
